oT-Based Unauthorized Power Tapping Detection & Protection System
🚀 Project Overview

This project detects unauthorized electricity tapping using IoT current sensors and automatically protects the distribution line by isolating the suspicious section.

❗ Problem Statement

Illegal power tapping causes:

Revenue loss for electricity utilities
Fire and electrocution hazards
Slow manual inspection processes
Lack of real-time monitoring between transformer and consumer meter
💡 Proposed Solution

The system uses CT current sensors, ESP32/NodeMCU, cloud communication, and an automated relay protection mechanism to continuously monitor feeder current and detect abnormal power usage.

🔧 Key Features
Real-time current monitoring
Smart anomaly detection
Tapping location identification
Automated relay isolation
Instant SMS/App alerts
Cloud dashboard support
🛠️ Tech Stack
Hardware
CT Current Sensor
ESP32 / NodeMCU
Relay Module
Software
Arduino IDE
MQTT / HTTPS
HTML, CSS, JavaScript
Firebase / Thing Speak
⚙️ System Workflow

CT Sensor → ESP32 → Cloud → Anomaly Detection → Alert → Relay Isolation

📈 Expected Impact
Reduce electricity theft losses
Improve public safety
Enable faster fault isolation
Reduce manual inspection effort
Provide a digital audit trail for enforcement
